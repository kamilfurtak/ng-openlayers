Additional work uses current Angular/OpenLayers capabilities: zoneless demo state, OnPush wrappers, map processing outside Angular's zone, in-place source URL updates, flat vector styles, cluster minimum distance, drawing trace options, layer zoom limits and resource disposal. These are verified independently rather than inferred from upstream parity.

This comparison is scoped to the inspected commit; it is not an exhaustive feature or performance comparison between the two libraries.
